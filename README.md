# RDPlayer Android

`RDPlayer Android` это Android-приложение для работы с личным self-hosted сервером RD Player.

Приложение открывает веб-интерфейс сервера во встроенном `WebView`, сохраняет сессию, умеет принимать ссылки через системный Share, воспроизводить медиа во встроенном или внешнем плеере и поддерживает обычные обновляемые release-сборки.

## Что умеет приложение

- первый запуск с настройкой адреса сервера
- проверка соединения с сервером перед сохранением
- встроенный `WebView` с сохранением cookies и сессии
- переходы по внутренним страницам внутри приложения
- открытие внешних ссылок во внешнем браузере
- приём ссылок и текста через системное меню **Поделиться**
- быстрые ярлыки приложения: `Home`, `Discover`, `Add`
- скачивание файлов через Android `DownloadManager`
- выбор режима воспроизведения:
  - встроенный плеер
  - внешний плеер
  - выбор каждый раз
- встроенный нативный плеер на `Media3 / ExoPlayer`
- продолжение просмотра с последней позиции
- диалог `продолжить / начать заново`
- жесты в плеере:
  - двойной тап для перемотки
  - свайп для изменения яркости
  - свайп для изменения громкости
- опция `Keep Screen On`
- обработка сетевых и HTTP-ошибок с понятными сообщениями
- поддержка Android TV / Leanback launcher

## Техническая информация

- **Название проекта:** `RDPlayer`
- **Пакет release:** `com.rdplayer.app`
- **Пакет debug:** `com.rdplayer.app.debug`
- **Минимальный Android:** `minSdk 26`
- **Целевой Android:** `targetSdk 34`
- **compileSdk:** `34`
- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **Плеер:** AndroidX Media3 / ExoPlayer
- **Сборка:** Gradle Kotlin DSL

Разделение `debug` и `release` сделано специально, чтобы debug-сборка не конфликтовала с установленной release-версией.

## Как работает приложение

### 1. Подключение к серверу
При первом запуске пользователь вводит URL своего сервера RD Player, например:

```text
http://100.x.x.x:7070
```

или

```text
https://your-tailnet-hostname:7070
```

После этого приложение может проверить соединение и сохранить адрес.

### 2. Основной режим
После настройки приложение открывает веб-интерфейс сервера во встроенном `WebView`.

- внутренние ссылки остаются внутри приложения
- внешние домены открываются в обычном браузере
- cookies и сессия сохраняются локально

### 3. Передача ссылок через Share
Если в Android выбрать **Поделиться** для текста или ссылки и указать `RD Player`, приложение откроет маршрут:

```text
/add?q=<переданный текст>
```

на настроенном сервере.

### 4. Воспроизведение медиа
Для медиа можно выбрать один из режимов:

- **Internal** , встроенный плеер
- **External** , внешний плеер
- **Ask Every Time** , спрашивать каждый раз

Во внешнем режиме приложение старается открыть ссылку через совместимый видеоплеер, например:

- `MPV`
- `VLC`
- `MX Player`

## Встроенный плеер

Встроенный плеер поддерживает:

- воспроизведение через `ExoPlayer`
- продолжение просмотра с сохранённой позиции
- ручной выбор: продолжить с прошлого места или начать сначала
- перемотку назад и вперёд
- полноэкранный режим с immersive UI
- управление яркостью и громкостью жестами
- сохранение позиции просмотра между запусками

## Ошибки и сетевое поведение

Приложение умеет показывать понятные сообщения для типичных проблем:

- DNS lookup failed
- Could not connect to server
- Connection timed out
- SSL/TLS connection failed
- 401
- 403
- 404
- 429
- ошибки 5xx

Это помогает быстрее понять, проблема в сети, в сервере или в авторизации.

## Подпись release

Для release-сборки проект поддерживает локальную подпись через keystore.

В репозиторий **не включены** чувствительные файлы:

- `keystore.properties`
- `keystore/`
- `*.jks`
- `*.keystore`
- `local.properties`

Это сделано специально, чтобы не публиковать приватные ключи и локальные настройки SDK.

Если планируются настоящие релизные обновления поверх уже установленных версий, важно сохранить исходный release keystore отдельно и безопасно.

## Основные компоненты

- `MainActivity` , точка входа, обработка запуска и share-intents
- `SetupScreen` , первоначальная настройка адреса сервера
- `MainScreen` , основной экран со встроенным `WebView`
- `SettingsScreen` , настройки приложения, URL, плеер, очистка данных
- `PlayerActivity` , встроенный полноэкранный плеер
- `AppPreferences` , локальные настройки и сохранение прогресса
- `RDWebViewClient` , внутренняя навигация, обработка ошибок и медиа-ссылок
- `DownloadHandler` , загрузка файлов через системный `DownloadManager`

## Для чего подходит проект

Этот проект подойдёт, если нужен Android-клиент для собственного RD Player сервера с такими целями:

- быстрый доступ к домашнему или VPS-медиа-серверу
- просмотр медиа через встроенный интерфейс
- удобная отправка ссылок на сервер из других приложений
- использование одного и того же сервера с телефона, планшета или Android TV

## Важно

Этот репозиторий содержит **исходный код Android-приложения**, а не сам веб-сайт RD Player.

Если у владельца аккаунта уже есть отдельный репозиторий с похожим названием для сайта или серверной части, этот проект нужно рассматривать именно как **Android-клиент**.
